SonarQube – návod na spustenie

  1. Spustite Docker Desktop.
  2. Spustite SonarQube: 
    docker run -d --name sonarqube-kpais -p 9000:9000 sonarqube:community
  3. Otvorte http://localhost:9000 a prihláste sa menom admin a heslom admin. Nastavte si nové heslo.
  4. Vpravo hore kliknite na ikonu používateľa → My Account → Security. Zadajte názov tokenu, kliknite Generate a token si skopírujte.
  5. V koreňovom priečinku projektu vytvorte súbor sonar-project.properties s týmto obsahom: 
    sonar.projectKey=alya-fiit
sonar.projectName=Alya-FIIT
sonar.sources=.
sonar.sourceEncoding=UTF-8
sonar.python.version=3.12

sonar.exclusions=\
  backend/.venv/**,\
  backend/htmlcov/**,\
  backend/data/**,\
  backend/**/*.egg-info/**,\
  frontend/node_modules/**,\
  frontend/dist/**,\
  site/**,\
  **/__pycache__/**
  6. V koreňovom priečinku projektu spustite analýzu (namiesto VAS_TOKEN vložte token z kroku 4): 
    docker run --rm -v "$(pwd):/usr/src" -e SONAR_HOST_URL=http://host.docker.internal:9000 -e SONAR_TOKEN=VAS_TOKEN sonarsource/sonar-scanner-cli
  7. Otvorte výsledky: http://localhost:9000/dashboard?id=alya-fiit
